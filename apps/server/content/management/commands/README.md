# Management Commands

## Available Commands

Currently, there are no active management commands. Content should be created manually through the Django Admin interface at http://localhost:8000/admin/

### Creating Content Manually

1. **Writers**: Go to Users → Writers → Add Writer
2. **Artists**: Go to Content → Artists → Add Artist
3. **Articles**: Go to Content → Articles → Add Article
4. **Events**: Go to Content → Events → Add Event

All content can be created, edited, and managed through the Django Admin interface.
